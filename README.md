# C&H Auction Radar — Multi Source

Αναβάθμιση του Auction Radar ώστε να συγκεντρώνει αυτόματα:

- **eAuction24** — πλειστηριασμούς Θεσσαλονίκης.
- **Prosperty** — πωλήσεις κατοικιών Θεσσαλονίκης (Δήμος + Περιφερειακοί Δήμοι).
- **Delfi Properties** — listings πώλησης/πλειστηριασμού με φίλτρο ενδιαφέροντος Θεσσαλονίκης.

## Τι κάνει αυτόματα

1. Το GitHub Action τρέχει **κάθε ώρα** και ενημερώνει `data/current.json`.
2. Κάθε listing κρατά **πηγή, original link, πρώτη/τελευταία εμφάνιση, τιμή, τ.μ. και αλλαγές**.
3. Στο άνοιγμα του site, ο browser συγκρίνει την τελευταία επίσκεψη και εμφανίζει τα **ΝΕΑ**.
4. Όλα τα listings περνούν στο υπάρχον persistence/ranking engine (`AuctionRadarPhase1`).
5. Στην πρώτη ενημέρωση της νέας ISO εβδομάδας, αποθηκεύεται αυτόματα snapshot της προηγούμενης στο `data/weekly/YYYY-Www.json` και ενημερώνεται το `data/weekly_index.json`.
6. Αν μία πηγή αποτύχει προσωρινά, οι άλλες συνεχίζουν και η εφαρμογή δείχνει το status κάθε πηγής.

## Deployment στο υπάρχον GitHub Pages repo

Αντικατάστησε/πρόσθεσε τα περιεχόμενα αυτού του φακέλου στο repository `auction-radar-thessaloniki` και κάνε ένα manual run του workflow **Update Auction Radar** από το GitHub Actions.

Το υπάρχον shortcut `START_AUCTION_RADAR.url` συνεχίζει να ανοίγει:

`https://kagioglou.github.io/auction-radar-thessaloniki/`

### GitHub settings

Το workflow δηλώνει `contents: write`. Αν το repository έχει πιο αυστηρή πολιτική, στο GitHub:
`Settings → Actions → General → Workflow permissions → Read and write permissions`.

## Σημαντικό για το ranking

Το αυτόματο `score_auto` είναι μόνο discovery score κυρίως από €/τ.μ. και **δεν είναι εκτίμηση ROI**. Η πραγματική «Κατάταξη Απόδοσης» του browser συνεχίζει να χρησιμοποιεί το C&H engine, στο οποίο μπορούν να συμπληρωθούν εκτιμώμενη εμπορική αξία, ενοίκιο, ανακαίνιση, λοιπά έξοδα και target bid.

## C&H Κατάταξη Απόδοσης — δύο σενάρια

Η Κατάταξη Απόδοσης υπολογίζει πλέον παράλληλα:

- **Άμεση πώληση:** συνολικό κόστος αγοράς + ανακαίνισης + λοιπών εξόδων έναντι εκτιμώμενης αξίας πώλησης. Ο στόχος **ROI ≥50%** εμφανίζεται ως ένδειξη και **δεν αποκλείει** ακίνητα με χαμηλότερο ROI.
- **3ετής εκμετάλλευση:** 36 μηνιαία μισθώματα + τελική πώληση. Για δίκαιη σύγκριση με την άμεση πώληση υπολογίζεται και ετησιοποιημένο ROI 3ετίας.
- Η προτεινόμενη ένδειξη στρατηγικής είναι `ΑΜΕΣΗ ΠΩΛΗΣΗ`, `3ΕΤΗΣ ΕΚΜΕΤΑΛΛΕΥΣΗ`, `ΚΑΙ ΤΑ ΔΥΟ` ή `ΧΡΕΙΑΖΕΤΑΙ ΕΚΤΙΜΗΣΗ`.
- Χωρίς εκτιμώμενη εμπορική αξία και/ή μίσθωμα, το σύστημα δεν δημιουργεί τεχνητό ROI· διατηρεί μόνο το discovery boost από €/τ.μ.

Τα 36 μισθώματα εμφανίζονται ως μικτά έσοδα μέχρι να προστεθεί ειδικό πεδίο λειτουργικών εξόδων μίσθωσης.
